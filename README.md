# 🚀 Task Tracker Full Stack App

A full-stack task management application built using modern web technologies.  
This app allows users to create, update, delete, and manage daily tasks efficiently.

---

## 🛠 Tech Stack

### Frontend
- React.js
- Axios
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

---

## ✨ Features

- ✅ Create Tasks
- ✅ Update Task Status
- ✅ Delete Tasks
- ✅ REST API Integration
- ✅ Full Stack Architecture (Client + Server)
- ✅ Clean Folder Structure

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Shubhamharanale7/task-tracker-fullstack.git
cd task-tracker-fullstack
```

### 2️⃣ Install Dependencies

#### Backend
```bash
cd server
npm install
```

#### Frontend
```bash
cd ../client
npm install
```

### 3️⃣ Run the App

#### Start Backend
```bash
cd server
npm start
```

#### Start Frontend
```bash
cd client
npm start
```

---

## 🌍 Environment Variables

Create a `.env` file inside the `server` folder:

```
PORT=5000
MONGO_URI=your_mongodb_connection_string
```
